## Prompt 1: my-length

~~~~text
Use the scheme-dev skill for this whole session.

We are starting problem S2 of CS F301 Assignment 2. The solution file is `code/3_q4.rkt` (it does not exist yet). The problem:

The function insert-if-short takes an atom x, a (possibly nested) list lst and an integer n, and inserts x at the front of every list whose length is less than n, at every level of nesting.
- The length of a list is the number of its top-level elements (atoms or sublists), measured on the original list, before any insertion.
- The top-level list is treated like every other list.
- Empty lists are not special: () has length 0, so it becomes (x) whenever 0 < n. This also holds for an empty top-level list.
- Elements of lst are atoms (digits or symbols) or lists. There are no dotted pairs. The element x is any atom. n is an integer with n >= 0.
- Hidden tests include nesting depth 100 and lists of 10,000 elements.

Scheme rules: only the following built-ins may be used: define, lambda, let, let*, letrec, named let, if, cond (with else), and, or, not, begin, quote (written '), cons, car, cdr, list, every composition of car and cdr up to four levels (cadr, cddr, caddr, cdddr, cadddr, cddddr, and so on), null?, pair?, eq?, assq, assoc, the arithmetic and comparison operators + - * < > <= >= =, max, display and newline. This problem additionally allows read. Nothing else from racket/base may be used. In particular: no set! or its relatives, no vectors, hash tables or strings, no loops (do, for), and no length, append, reverse, map, filter, member, memq, list-ref or list-tail. If you need such a function, write your own helper.

The file starts with `#lang racket/base` and contains only definitions: no top-level calls and nothing printed when the file is loaded. The grader appends its own calls to the end of the file and runs `racket 3_q4.rkt`.

Task for this prompt only: create `code/3_q4.rkt` with the function `(my-length lst)`, which returns the number of top-level elements of the list lst (atoms or sublists, each counting as one). Make it tail recursive with an accumulator. Do not write any other function yet.

Then check it on a temporary copy of the file with calls appended: (), (1 2 3), ((1 2) (3 4 5) (6) ()) (which has length 4), (((1) 2) (3) ((4 5 6) ())) (length 3), and a list of 10,000 elements. Report the results.
~~~~

**Outcome:** Kept as written. Lengths 0, 4 and 3 for (), the first and the second handout list on our own run; a 10,000-element list also works.
