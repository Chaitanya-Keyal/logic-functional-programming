## Prompt 1: candidate/1, the clue-independent generator

~~~~text
Use the prolog-dev skill for this whole session.

We are starting problem P1 of CS F301 Assignment 2. The solution file is `code/3_q1.pl` (it does not exist yet). The puzzle:

Four friends (Alex, Ben, Carla, Dana) each have a department, a favorite language and a project preference.
- Department: research, development, design, testing
- Favorite language: python, java, c++, javascript
- Project: AI, web, embedded, data

Every friend has a different value for each attribute, so each of the four values of each attribute is used exactly once.

A solution is a Prolog list of four terms p(Name, Dept, Lang, Project), in the order Alex, Ben, Carla, Dana. The names are the quoted atoms 'Alex', 'Ben', 'Carla', 'Dana'. The values are exactly these atoms: research, development, design, testing; python, java, 'c++', javascript; 'AI', web, embedded, data.

Task for this prompt only: create `code/3_q1.pl` containing
1. the `use_module` directive for the library this predicate needs, and
2. one predicate, `candidate(-Solution)`, that enumerates on backtracking every fully filled-in solution in the format above: every combination of a permutation of the departments, a permutation of the languages and a permutation of the projects, so 24 x 24 x 24 = 13,824 lists.

The generator must not use any clue. The clues will be separate clue/2 clauses that are checked after generation, so that counting with any subset of the clues stays correct. Do not write clue/2, main/0 or count_solutions/2 yet.

File rules: no assert, retract or global variables, no initialization directive, no halt, only the libraries lists, apply, yall and aggregate, and nothing printed when the file is loaded.

When you are done, check that the file loads silently and that `aggregate_all(count, candidate(_), N)` gives N = 13824, and report what you ran and the results.
~~~~

**Outcome:** Kept as written. We checked that the file loads silently and that candidate/1 yields 13,824 distinct, well-formed lists.
